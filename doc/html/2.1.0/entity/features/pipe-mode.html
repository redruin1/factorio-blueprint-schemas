Pipe Mode

Type: object

Allows the entity to configure how it should broadcast it's fluid contents to the circuit network.

Default: 1

  • None
  • Pipe
  • Pipeline

None

Type: const

Do not broadcast this pipe's/pipeline's contents.

Specific value: 0

Pipe

Type: const

Broadcast only the volume in this pipe/storage tank.

Specific value: 1

Pipeline

Type: const

Broadcast the volume of the entire connected pipe network for this fluid.

Specific value: 2
